# STM32 FOC 学习 Skill

这是一个面向学术学习和硬件实验的电机控制项目。最终目标是学习无感 FOC，但必须通过可观察、可复现实验逐级推进。除代码标识符、公式变量、文件名和必要的英文术语外，默认使用中文回答。

## 开始工作前

先检查仓库当前代码，读取：

- `references/project-baseline.md`：当前项目基线和代码边界；
- `references/roadmap.md`：控制算法学习路线；
- `references/control-experiments.md`：采样频率、调试、观测和验收方法。

判断用户要求、已经通过硬件验证的最新里程碑，以及能够产生有效证据的最小下一步。解释或规划请求不修改代码；实现请求只修改相关范围，并尽可能完成编译或静态检查。

## 固定学习路线

1. 编码器原始角度、跨零点、连续机械角和速度估算；
2. 极对数、电角度零点标定和编码器有感换相；
3. 电压模式速度闭环；
4. 同步电流采样；
5. 有感电流环 FOC；
6. 位置环和轨迹控制；
7. 电机参数与电压模型验证；
8. 编码器参与验证的无感 SMO + PLL；
9. 有感/无感受控切换；
10. 可选的低速、零速 HFI 研究。

不要跳过前置条件直接堆叠算法。反电动势观测器在接近零速时缺乏可观测性；HFI 是独立的高级课题，不是简单调观测器增益即可解决的问题。

## 保持当前项目架构

- 控制模式、状态和调度先放在 `User/StateMachine.c/.h`；
- 变换、SVPWM、PI 和观测器初期放在 `User/Foc.c/.h`；
- 扩展 `User/Enconder.c/.h`，不要擅自改正已有文件名；
- 外设读写放在 `User/HardWare_Driver.c/.h`；
- `User/Vofa.c/.h` 只负责遥测，不参与控制决策；
- 尽量保持 `Core` 为 CubeMX 生成层，把手写控制逻辑放进 `User` 或用户代码区；
- 不为了一个里程碑重构无关模块。
- 优先保留少而明确的状态变量：只被单个函数临时使用的中间量应作为局部变量，不长期存入结构体。
- 在不改变控制公式、周期和可观测性的前提下，优先采用短小、线性、易验证的实现；避免同时保存可由现有状态直接推导的重复量。

## 源文件编码与教学注释

- `Core`、`User` 的 C/H 文件按 GB2312（Windows 代码页 936）读写；修改前检测原编码，修改后重读检查，禁止静默转 UTF-8 或批量重编码其他文件。
- 发现 `�`、`锟斤拷` 等乱码时先修复。为新增配置、结构体变量、函数添加中文注释，写清单位、方向、周期、输入输出、有效条件和复位行为；跨零及失联恢复说明原因。

## 必须明确的控制约定

在实现依赖公式的功能前，明确并用中文说明：电机极对数、机械正方向、编码器方向、U/V/W 相序、Clarke/Park 符号、电角度 offset 的正负号、单位和每个控制环的 `Ts`。

统一使用弧度、rad/s、安培、伏特和秒；RPM 只用于显示。统一实现 `wrap_0_2pi` 和有符号的 `wrap_pm_pi`，不要在各处重复写不一致的跨零点处理。

基本关系为：

`theta_e = wrap_0_2pi(direction * pole_pairs * theta_m + electrical_offset)`

但正负号必须用实验确认。电机能转不代表角度约定正确，还要观察平滑性、电流、方向和角度误差。

## 控制周期约定

- PWM、当前电流环、SMO、PLL：默认 20 kHz；
- 编码器读取和速度环：初期默认 1 kHz；
- 位置环：100～500 Hz；
- VOFA 遥测：约 100 Hz。

当前 MT6816 是阻塞式两次 SPI 读取，不能放入 20 kHz PWM 中断。快速控制环只能使用最近一次有效数据，并应让数据年龄可观测。

## 每次只做一个实验

每个里程碑都必须用中文给出：

1. 假设：这次改动应该产生什么现象；
2. 概念和最小公式；
3. 代码边界：文件、状态变量、输入、输出和周期；
4. VOFA 需要观察的变量；
5. 可复现的台架实验步骤；
6. 通过标准；
7. 按优先级排列的故障排查顺序。

PI 调试必须有输出限幅和抗积分饱和。先用比例项确认方向和量纲，再加入积分项。没有实测数据时，不要伪造最终 PI 参数。

## 无感学习原则

开发无感时保留 MT6816，并行运行编码器和观测器。至少输出：编码器电角度、观测器电角度、`wrap_pm_pi` 角度误差、编码器速度、PLL 速度、观测器内部量、有效标志和饱和标志。

第一种无感算法优先采用“反电动势滑模观测器 SMO + PLL”。在此之前必须具备同步且已校准的相电流采样、正确的电流符号和比例、可用的 `Rs`/电感参数、合理的实际施加电压估算、稳定的有感电流环和编码器参考数据。

只有当观测器在规定速度和负载范围内持续跟踪编码器后，才允许它参与换相。切换必须有锁定条件、滞回、保持时间、失败回退和可观测状态。

报告以下内容：完成的里程碑和范围、修改文件、控制周期、引入的公式或约定、已完成的编译/静态检查、仍需进行的硬件实验、VOFA 观测变量、通过标准以及下一步解锁的里程碑。没有硬件证据时，明确写“软件已准备，实验尚未完成”。
