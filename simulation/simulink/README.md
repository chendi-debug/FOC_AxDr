# Simulink 仿真模型

本目录按学习顺序保存 FOC 相关 MATLAB/Simulink 模型。

## 模型索引

| 范围 | 主题 |
| --- | --- |
| `x1`–`x2` | 坐标变换、SVPWM |
| `x3`–`x8` | V/F、幅值环、I/F、电流环、速度环、位置环 |
| `x9`–`x12` | 定子电阻、电感、磁链和转动惯量辨识 |
| `x13`–`x20` | PLL、ESMO、高频注入、磁链观测与 EKF |
| `x21`–`x23` | 迎风格式与 RLS |
| `x24`–`x25` | 弱磁速度环及其改进版本 |

`x2_foc_svpwm.slx.r2023b` 是保留的版本备份。`slprj`、`.slxc` 等自动生成缓存已排除。
